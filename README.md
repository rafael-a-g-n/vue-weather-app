# 🌦️ Vue Weather App

Welcome to the **Vue Weather App**! This project is a sleek and modern weather application built using the power of Vue.js and other web technologies. It provides real-time weather updates, a clean user interface, and the ability to search for weather information by location. 🌍☀️🌧️

---

## 🚀 Features

- 🌡️ **Real-Time Weather Information**: Get instant weather updates for any location.
- 🔍 **City Search**: Search weather conditions by city name.
- 📊 **Dynamic UI**: Responsive and intuitive design for a seamless user experience.
- 🎨 **Clean Design**: Minimalistic and highly readable interface.
- 🌐 **Global Coverage**: Supports weather data for locations worldwide.

---

## 📦 Installation

Follow these steps to get the app up and running on your local machine:

1. Clone the repository:
   ```bash
   git clone https://github.com/rafael-a-g-n/vue-weather-app.git
   cd vue-weather-app
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development sarver:
   ```bash
   npm run serve
   ```
4. Open the app: Visit http://localhost:8080 in your browser.
